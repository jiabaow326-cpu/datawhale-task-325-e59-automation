# 可复用模板：重复电脑操作的 AI 辅助提示

把方括号内容替换为已核实、已获授权的练习信息。**不要粘贴真实个人信息、客户/员工资料、账号、凭证、公司机密或未经授权的数据。**

## A. 操作契约提示

```text
我想自动化一个重复电脑流程。请先只写操作契约，不要写代码，不要猜缺失信息。

使用环境：[操作系统与已批准工具]
输入目录：[仅限练习副本目录]
人工步骤：[逐步描述]
输入格式/必需字段：[已确认字段]
输出内容及命名规则：[已由负责人确认]
汇总规则：[字段、筛选范围、分组和排序]
批准人/审批来源：[本人线下核实后填写；没有则标待确认]

安全约束：预览优先；不改、不删、不覆盖来源；输出仅写入全新目录；缺文件、冲突、字段异常、路径越界或未核准时整批停止；不联网、不安装、不发邮件/消息；回滚时只隔离生成目录并保留日志。
请输出已知事实、待确认问题、验收检查点和停止条件。不要生成或猜电话号码、审批结论、真实文件内容。
```

## B. 脚本审查提示

```text
请对以下脚本做静态安全审查，不运行它。逐项检查默认是否为预演、是否有显式应用开关、来源是否只读、目标是否只能是新建目录、路径穿越/软链接/重名/缺文件/CSV 字段错误如何处理、是否有覆盖或删除、是否联网、输出日志能否核验。
每项给出代码证据与“通过/不通过/未知”。只要有一项不通过或未知，结论就是暂停；不要把未知写成通过。
[粘贴无敏感信息的代码]
```

## C. 预演核对提示

```text
只比较下面的操作契约与本地预演结果。逐行指出来源、目标、文件数、字段/汇总范围和潜在覆盖差异。不要代替我批准正式流程。
如果有路径越界、来源缺失、重复目标、未核准或目标目录已存在，结论为“暂停，不执行”。
[粘贴已脱敏契约和预演结果]
```

## D. 运行后核对提示

```text
请只根据提供的源样例、摘要 CSV 与 SHA-256 清单复核行数、分组汇总和副本一致性。请列出每个计算过程，区分算出的事实与无法验证之处。不一致时建议隔离输出并保留源文件；不要提出删除源文件或覆盖旧结果。
[粘贴虚构样例数据与输出]
```

## E. 流程采集卡

见同目录 `流程采集卡.md`。AI 的输出仅作草稿；数据范围、权限、审批人、生产执行与异常决策必须由有权人员确认。
