# E59 重复电脑操作自动化：从人工步骤到可回滚批处理

> 练习目标：把重复的“核对文件清单—复制并规范命名—汇总 CSV”做成安全的本地脚本。全部文件为虚构样例。不要把客户、员工、财务或公司机密原件上传给 AI；即便脱敏，也要先确认组织授权和工具规则。AI 可以起草与检查代码，是否用于正式数据仍由有权人员决定。

## 准备

解压本包，确认文件夹中有 `scripts/safe_batch.py` 与 `materials/`。需要 Python 3.10+，不需要安装额外套件。练习时只读写此包的副本；先不要把任何输入拖进正式共享盘。

## 第 1 步：把重复动作写成可检查的操作契约

**为什么现在做：** “帮我自动整理一下”没有明确边界，AI 可能擅自移动、覆盖或删除文件。先把人现在如何做、输出该长什么样讲明白，脚本才能按约束生成。

**要完成什么：** 手动跟做一次样例流程，填好 `templates/流程采集卡.md`：输入目录、命名规则、汇总字段、谁确认规则、错误时停止条件、允许写入的输出位置。保留来源文件，不在本步改名。

**本步材料：** `materials/source/` 三个样例 CSV、`materials/manifests/范围说明_v2_当前版.txt`、`templates/流程采集卡.md`。

**可直接复制给 AI 的提示词：**

```text
我想自动化一个只针对练习副本的流程。请先根据下列说明产出“操作契约”，不要写代码，也不要推测缺失信息。
输入目录：[填写]
目前人工步骤：[逐条填写]
期望输出：[文件名、字段、排序]
禁止事项：不得修改/删除来源，不得覆盖既有输出，不得访问输入目录以外的路径；缺文件、重名、字段错误或未核准必须停止。
请列出：已知事实、待我确认的问题、成功检查点、停止条件。不要补造文件名、电话号码、账号或审批人。
```

**完成标志：** 采集卡每项都已填写，且流程负责人确认过范围、命名、汇总字段和停止条件；你能用自己的话说出来源保持不变、输出只能进入新目录。把这份契约作为第 2 步判读材料。

## 第 2 步：侦测清单里的陷阱，不让冲突流进脚本

**为什么现在做：** 清单中某一行写错，就可能把两家门店合并覆盖，或让脚本把旧数字当作现状。自动化应在复制前报告冲突并停止。

**要完成什么：** 对照范围说明 v2、已替代 v1、v2 清单和重复副本，填写 `reference/清单核验记录.md` 的“问题与证据”部分。再用待核验清单运行预演：

```powershell
python scripts/safe_batch.py --source-dir materials/source --manifest materials/manifests/处理清单_v2_待核验.csv --output-dir results/blocked-demo
```

预期看到 `BLOCKED`、重复目标名、找不到东区源文件；脚本不会创建输出目录。复制清单副本不代表多出了一份业务记录。

**本步材料：** 第 1 步操作契约、`materials/manifests/` 全部文件、脚本的预演结果、`reference/清单核验记录.md`。

**可直接复制给 AI 的提示词：**

```text
仅根据我粘贴的文件内容，核对文件版本、重复件、来源是否存在、目标名称是否冲突和审批字段是否完整。每个判断必须引用具体文件名/行号；区分“确认事实、冲突、缺项、待负责人确认”。不要替我猜测正确文件名或删掉可疑行。只要有未解决项，就输出“暂停执行”。

[粘贴虚构练习文件内容；不要贴个人或公司真实数据]
```

**完成标志：** 核验记录明确列出每个问题及证据；待核验清单运行以退出码 2 停止；`results/blocked-demo` 不存在。问题与证据表作为第 3 步的脚本安全需求。

## 第 3 步：给脚本加护栏，先审规格再审实现

**为什么现在做：** 识别错误数据之后，需要把“检测到就停止”写进脚本，而不是让操作者每次记住口头提醒。边界先明确，才不会让 AI 生成有破坏性的快捷操作。

**要完成什么：** 对照随包的 `scripts/safe_batch.py` 逐项核对：默认预演、必须显式 `--apply`、只复制、来源和输出目录不得重叠、校验文件存在与字段、重名则阻断、输出目录已存在就拒绝、生成校验清单和汇总。用 `templates/AI提示词模板.md` 要 AI 检查脚本；不要接受自动删旧文件、批量覆盖或无审批直接执行建议。

**本步材料：** 第 2 步问题与证据、`scripts/safe_batch.py`、`templates/AI提示词模板.md`。

**可直接复制给 AI 的提示词：**

```text
请审查以下 Python 批处理脚本的文件安全，不要执行代码。逐项检查：默认是否只预览；复制是否仅写入新建输出目录；来源目录会否被改写；路径穿越、缺源文件、重复目标、重复来源、未核准、CSV 缺字段、输出已存在时会否整批停止；输出是否含源/目标文件 SHA-256 记录；是否存在删除、覆盖、联网或隐式执行。
请逐项给“通过/不通过 + 对应代码行或证据 + 最小修正”。不知道时标注未知，不要编造结论。
```

**完成标志：** 你已在人工审阅表逐项打勾；确认代码不会联网、不会改来源、不会删除，并知道只在新输出目录落盘。可运行性与护栏检查表作为第 4 步验收条件。

## 第 4 步：预演核准清单，逐条人工复核计划

**为什么现在做：** 有护栏的脚本仍可能因为输入清单错误而产生错误结果。先在不写文件的模式看完整计划，比事后找回覆盖文件可靠。

**要完成什么：** 查看参考答案中的已核准演练清单，并用它做一次预演：

```powershell
python scripts/safe_batch.py --source-dir materials/source --manifest materials/manifests/演练已核准清单.csv --output-dir results/demo-run-001
```

核对三行映射均一对一、输出目录全新、计划汇总六条明细。只有每项都符合操作契约，才可以进入第 5 步。

**本步材料：** 第 1 步操作契约、第 2 步核验记录、第 3 步安全需求、`materials/manifests/演练已核准清单.csv`、预演输出。

**可直接复制给 AI 的提示词：**

```text
帮我把以下预演计划与操作契约逐行对照。仅指出不匹配项，列出来源、目标、汇总范围、是否会覆盖/修改来源。不能因为“看起来合理”就代替负责人核准。若计划中有缺项、重复名、目录不安全或金额/行数不一致，结论必须为“暂停，不加 --apply”。
[粘贴本地生成的预演文本与不含敏感信息的契约]
```

**完成标志：** 计划为 3 个来源文件分别复制成不同目标名，汇总 6 行；输入范围和目标目录已由本人确认。把核对过的预演保存在练习记录中，作为第 5 步运行前最后检查。

## 第 5 步：只在一次性副本应用，核对后演练回滚

**为什么现在做：** 自动化只有在输出正确且出了问题能隔离时才有价值。本步仍是虚构练习，不代表可以直接用于生产。

**要完成什么：** 再读一遍第 4 步通过的计划，然后显式加 `--apply`：

```powershell
python scripts/safe_batch.py --source-dir materials/source --manifest materials/manifests/演练已核准清单.csv --output-dir results/demo-run-001 --apply
```

打开 `results/demo-run-001/summary.csv` 与 `copy_manifest.csv`。逐一核对三份复制文件、六条输入记录、门店/品项数量与金额、SHA-256；抽样比对源文件与输出副本哈希。任何不一致就停止，不把结果送入业务系统。

**本步材料：** 已通过的预演记录、第 3 步审查表、`results/demo-run-001/` 输出、`reference/验收答案与回滚说明.md`。

**可直接复制给 AI 的提示词：**

```text
请根据我给的虚构样例汇总表和源文件内容，重新手算每家门店每个品项的数量/金额，并与脚本输出核对。只列出差异，不要推断没有提供的记录。若有差异或哈希不一致，建议暂停并隔离本次输出；不要删除或覆盖任何文件。
```

**完成标志：** 输出计数和金额与参考答案一致、来源哈希与副本哈希逐份匹配、来源目录时间/文件内容未变；桌面演练记录了“输出未被系统接受时，将整次输出目录移动到隔离目录，保留原件和日志”，不执行删除。完成后把操作契约、核验记录、脚本版本和演练日期存档。若不合格，只改练习副本并重做第 4、5 步；真实数据上线要另走组织审批。
